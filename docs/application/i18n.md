# Internationalisierung

!!! note
    Die i18n-Funktion wird derzeit nicht aktiv genutzt. Die Templates enthalten ihre Texte inzwischen größtenteils direkt auf Deutsch, und die Anwendung verwendet immer das Locale `de`. Texte passt man am einfachsten über ein [eigenes Theme](develop.md#eigenes-theme) oder ein eigenes [`theme_package`](develop.md#templates-ersetzen) an.

Die übersetzbaren Texte der Anwendung `briefkasten` stehen in einem `gettext`-Nachrichtenkatalog unter `application/briefkasten/locale/`:

- `briefkasten.pot` – die Vorlage mit allen Texten
- `de/LC_MESSAGES/briefkasten.po` – die deutsche Übersetzung
- `de/LC_MESSAGES/briefkasten.mo` – die kompilierte Übersetzung, die die Anwendung lädt

Um die Texte zu aktualisieren (alle Kommandos in `application/`):

1. Texte aus den Templates und dem Python-Code in die Vorlage extrahieren, mit [lingua](https://pypi.org/project/lingua/):

    ```
    $ uvx --from lingua --with chameleon pot-create -o briefkasten/locale/briefkasten.pot briefkasten
    ```

2. Die Übersetzung mit der neuen Vorlage abgleichen, mit [Babel](https://babel.pocoo.org/):

    ```
    $ uvx --from Babel pybabel update -D briefkasten -i briefkasten/locale/briefkasten.pot -d briefkasten/locale
    ```

3. `briefkasten/locale/de/LC_MESSAGES/briefkasten.po` bearbeiten.

4. Den Katalog kompilieren:

    ```
    $ uvx --from Babel pybabel compile -D briefkasten -d briefkasten/locale --statistics
    ```

Nach einem Neustart der Anwendung sind die neuen Übersetzungen aktiv.
