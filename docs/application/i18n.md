# Internationalization

!!! note
    The i18n feature is currently not actively supported anymore - the workaround is to translate the texts using the theming mechanism, where you can replace tagged markup with translated versions.

All user facing texts of the `briefkasten` application are translated using a `gettext` message catalog. To customize and update these messages you must:

- extract the messages into the catalog template
- update the catalog file
- compile the catalog

The required tools ([lingua](https://pypi.org/project/lingua/) and [Babel](https://babel.pocoo.org/)) are not part of the application's dependencies, but can be run ad hoc via `uvx`. All of the following commands need to be run inside the `application` directory.

To find untranslated texts in the Python code and the templates and create entries for them, do this:

```
uvx --from lingua pot-create -o briefkasten/locale/briefkasten.pot briefkasten
uvx --from Babel pybabel update -i briefkasten/locale/briefkasten.pot -d briefkasten/locale -D briefkasten
```

Then you can edit the message catalog in `briefkasten/locale/XX/LC_MESSAGES/briefkasten.po`.

Finally:

```
uvx --from Babel pybabel compile -d briefkasten/locale -D briefkasten
```

After restarting the application, the new translations will be active.

For more details check these links:

- [Pyramid: Internationalization and Localization](https://docs.pylonsproject.org/projects/pyramid/en/latest/narr/i18n.html)
- [Chameleon: Internationalization](https://chameleon.readthedocs.io/en/latest/reference.html#translation-i18n)
- [Babel: Command-Line Interface](https://babel.pocoo.org/en/latest/cmdline.html)
